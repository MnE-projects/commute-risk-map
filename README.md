# 通勤風險共創地圖 SAMPLE

以 Leaflet 與 OpenStreetMap 建立的通勤風險共創地圖原型，將員工回報的道路、路口、時段與風險類型轉為可搜尋、可篩選的地圖資訊。

本原型不限於特定交通工具，可涵蓋：

- 機車
- 汽車
- 自行車
- 步行
- 公車
- 捷運或台鐵轉乘
- 公司接駁
- 停車場進出動線
- 其他上下班通勤方式

## 專案目的

員工每天通勤時觀察到的危險路口、視線死角、大型車動線、照明不足、積水及路面異常等資訊，通常分散在個人經驗中，不易形成可供其他同仁使用的共同資訊。

本專案透過簡易回報與互動地圖，讓分散的通勤風險資訊可以被看見、搜尋及整理，作為員工通勤提醒、安全宣導及後續改善評估的參考。

## 展示功能

- 通勤風險點位顯示
- 關鍵字搜尋
- 風險類型篩選
- 行政區篩選
- 回報清單與地圖定位
- 全部回報範圍顯示
- 桌面與手機響應式介面
- 手機地圖聚焦模式
- Microsoft Lists 回報入口
- GeoJSON 地圖資料讀取
- 地圖標記與資訊彈窗
- 初次使用網站導覽

## 使用流程

1. 使用者透過 Microsoft Lists 表單提出通勤風險回報。
2. 回報資料保存於 Reports 清單。
3. 地點資料經整理後，匹配公開道路、路口或公開地標中心座標。
4. 可公開欄位轉換為 GeoJSON。
5. Leaflet 讀取 GeoJSON，並將點位呈現在 OpenStreetMap 底圖上。
6. 使用者可依地點、風險類型及行政區查看回報內容。

目前原型採定期更新方式，新回報不一定會立即顯示於公開地圖。

## 資料與隱私原則

公開地圖不應包含：

- 姓名
- 公司電子郵件
- 員工編號
- Microsoft 帳號
- 建立者或修改者
- 完整通勤軌跡
- 個人住址
- 車牌
- 其他可辨識個人的資訊

地圖座標使用公開道路、路口或公開地標位置，不使用員工 GPS、住址或完整通勤起訖點。

目前 Microsoft Lists 表單使用公司帳號確認填寫資格，表單擁有者可能看到填寫者的名稱與電子郵件。相關身分資訊不會顯示於公開地圖或回報清單。

## SAMPLE 資料聲明

目前網站中的點位、內容與統計皆為虛構 SAMPLE 資料，僅用於驗證介面、功能與資料流程。

展示內容不代表：

- 真實事故紀錄
- 公司正式風險判定
- 道路管理單位的調查結果
- 特定道路的事故率
- 特定交通工具的安全程度或安全排名

網站中的「社群回報」尚未經道路管理單位驗證。使用者仍應依現場交通、天候、道路及自身狀況作出安全判斷。

回報數量也不能直接解讀為事故率，因為目前沒有各交通方式的通勤人次、里程或使用頻率作為比較基準。

## 技術架構

- Microsoft Lists：回報資料收集與保存
- CSV：原型階段資料匯出
- Python：CSV 轉 GeoJSON
- GeoJSON：公開地圖資料格式
- Leaflet：互動地圖介面
- OpenStreetMap：道路底圖
- GitHub Pages：SAMPLE 網站託管
